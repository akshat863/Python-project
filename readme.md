# Student Fee Management System

A simple, console-based Python application for managing student fee records. This system allows you to easily track student enrollments, process fee payments, and identify students with pending dues.

## Features
- **Add Student:** Register a new student with a unique Roll Number, Name, and Course (BCA, BTech, or MBA).
- **Pay Fee:** Process payments for existing students. The system automatically validates the payment amount against the remaining due balance.
- **Search Student:** Quickly look up a student's details, total fee, paid amount, remaining due, and current payment status (Paid / Partial / Unpaid) using their Roll Number.
- **Pending Dues:** Generate a list of all students who still have outstanding fees.
- **Persistent Storage:** All student data is saved to a local `fees.txt` file, ensuring no data is lost when the program is closed.

## Prerequisites
- **Python 3.x** installed on your system.
- No external libraries are required (uses only built-in modules).

## File Structure
- `main.py`: The main Python script containing the application logic.
- `fees.txt`: The text file automatically generated by the script to store student data (comma-separated).

## How to Run

1. Ensure you have Python installed on your computer.
2. Download or copy the `main.py` file to a folder on your computer.
3. Open your terminal (or Command Prompt / PowerShell).
4. Navigate to the folder where `main.py` is located.
5. Run the script using the following command:

   ```bash
   python main.py
